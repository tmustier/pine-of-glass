# Pine of Glass 0.15.3

Running status now uses Pi's selected accent, including the terminal-derived `system`
theme. Existing Cachemire and Meantime notices, ledgers and clocks recolour when the
theme changes. Historical facts, aligned columns and widget order stay fixed.

The shared text and widget code is simpler: one cached text value replaces separate
resolution and widget state. Typed theme calls no longer hide programming errors.
Tests exercise native components and SDK-created ledgers; redundant constant-only
and fabricated broken-theme checks are removed.

The READMEs include dark and light captures of the same live ledgers, refreshed
Meantime screenshots and updated colour guidance. [PR #152](https://github.com/tmustier/pine-of-glass/pull/152).

## Validation

- Pi 0.87.1, the locked runtime: lint, typecheck and all 415 tests pass
- Pi 1.1.0: focused theme and widget-order contracts, typecheck and the full real-TUI smoke suite pass
- live `openai-codex/gpt-6.1-sol` calls with medium thinking execute bash; theme switches recolour active tools and existing ledgers, with unchanged historical text
- an independent code review found no correctness issues

The system-theme captures supply dark and light palette replies to Pi's own theme
resolver. They test extension integration, not physical-terminal OSC query transport.

## Known limits

This is a theme fix, not a full Pi 1.1 compatibility release. Six existing current-Pi
contracts still fail: three model-catalogue checks, the removed startup Themes
listing, an old status Text constructor assertion and the pager's image-conversion
interface. Traceline's Drill viewer may lose non-PNG previews on kitty-protocol
terminals. This release does not fix or live-verify that separate risk.

The locked-runtime full smoke run also encounters a pre-existing fullscreen
reasoning-click viewport lookup failure. It reproduces on unchanged `main`; the
full Pi 1.1 smoke suite passes.

The minimum Pi version and locked dependencies are unchanged.

## Update

```bash
pi update --extensions
```

Restart Pi to load the release. Cachemire remains experimental; Meantime remains
experimental and opt-in.
