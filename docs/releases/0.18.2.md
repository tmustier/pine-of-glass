# Pine of Glass 0.18.2

A Contextimate fix for bundled Pi, which includes the standard npm install of Pi.

## Request-only attribution works in bundled Pi

Since 0.18.0, Contextimate compares each outgoing OpenAI Responses, Codex, Azure or
Anthropic request with the saved conversation, so it can count text added only for that
request. In bundled Pi, it could not load the Pi AI helpers it used for this comparison.
Bundled Pi is what the standard `npm install -g` install (since Pi 0.84.3) and Homebrew
run. After each assistant turn, Pi printed
`Cannot find module '@earendil-works/pi-ai'`, and the `Request-only` row missed that
turn's additions.

Contextimate now applies the text rules Pi uses when it replays a conversation, without
loading Pi's helpers. It skips failed and aborted replies, drops another model's
thinking as Pi does, and leaves out signed or redacted thinking. Request-only additions
are counted again, and the error no longer appears.
