# Pine of Glass 0.18.4

Traceline links pull request and issue numbers in record headlines to their GitHub pages.

## Click a PR or issue number to open it

Rows such as `opened PR #88 $ gh pr create --fill`, `merged PR #87` and `closed #12`
now link the number to its page. In fullscreen mode, click the number to open it;
clicking anywhere else on the row still expands it. Outside fullscreen, use your
terminal's link gesture.

The address comes from the command's own evidence: the URL `gh pr create` or
`gh issue create` prints, `owner/repo#N` in gh's confirmation, `--repo` or a PR URL in
the command, or the `url` of a `gh pr view --json state,url` check. When nothing names
the repository, the number stays plain text.

Links follow Pi's hyperlink setting, so terminals Pi does not recognise show plain text
as before. If your terminal supports links but Pi does not detect it (Rex, for
example), set `"terminal": { "hyperlinks": true }` in Pi's settings or `PI_HYPERLINKS=1`.

Your own vocabulary entries can link their datum with an `href` template, such as
`"https://example.com/deploys/{name}"`.

Added in [PR #188](https://github.com/tmustier/pine-of-glass/pull/188).

## Verification

Lint, typecheck and all 541 tests pass; the new tests fail without the change. A live
Pi 1.4.0 fullscreen session with GPT-6.1 Sol ran `gh pr create` (a stub on `PATH`):
clicking the number opened the PR URL once without expanding the row, clicking the verb
expanded it, and with `PI_HYPERLINKS=0` the same click expanded the row and opened
nothing. Cmd-click outside fullscreen was not tested.
