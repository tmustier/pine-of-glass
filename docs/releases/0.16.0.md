# Pine of Glass 0.16.0

Traceline now shows the tools called inside codemode scripts, explains failed calls,
and keeps long command sequences readable. The release also updates development and
tests to Pi 1.2.0 and fixes the compatibility gaps documented in 0.15.3.

## Nested tool calls

A codemode row now summarises its nested calls instead of showing JavaScript source.
The summary includes tool counts, paths, nested failures and truncated output. A
completed script with a failed nested call shows a warning rather than hiding the
failure behind a success bullet.

The per-call ledger is visible by default, with repeated calls and related reads
folded together. Ledgers longer than 12 lines after folding start collapsed. You can
change the behaviour with `revealLedgers` and `ledgerMaxLines` in the family config.
Click the row in fullscreen mode to fold or reveal its ledger, or use Drill to see
the complete script, calls and output.

Tools that call other tools through Pi's `ctx.executeTool()` use the same display.
Nested-call records require Pi 0.99 or later; older Pi keeps the native row. Nested
result sizes are available only for calls made in the current session.

PRs [#145](https://github.com/tmustier/pine-of-glass/pull/145) and
[#158](https://github.com/tmustier/pine-of-glass/pull/158).

## Failures, checks and command rows

- Failed rows show a reason such as `exit 2`, `timeout 30s`, `aborted`, `no matches`
  or the tool's error text. Nested failures and cancellations appear in the ledger.
- Test, type-check, lint and format rows show the result when the output proves it.
  Reruns keep their own counts, failed test-file loads cannot read as passes, and
  failed checks behind a successful shell pipeline show a warning.
- Long compound bash rows wrap at command boundaries, up to four lines. Leading
  `cd` paths shorten before command names do, so the commands remain visible.
- Edit and write rows show the short header and change counts again. File previews
  and diffs remain in the expanded row.

## Pi compatibility

Development and tests now use Pi 1.2.0 instead of 0.87.1. The contract checks follow
the current catalogue, startup, status-line and image interfaces. On Pi 1.x, Drill
again uses Pi's image conversion for JPEG and other non-PNG previews on
kitty-protocol terminals. The minimum supported Pi remains 0.86.0.

The internal parsing and rendering code is simpler, and the smoke tests now account
for Pi 1.x viewports and startup notices.

PRs [#154](https://github.com/tmustier/pine-of-glass/pull/154),

## Validation

- Lint, typecheck and all 457 tests pass on the locked Pi 1.2.0 runtime.
- The full real-TUI smoke suite passes, including clicks, reasoning, Drill, pager
  fidelity, nested sessions, startup and reload.
- A live `openai-codex/gpt-6.1-sol` run with medium thinking executes three codemode
  scripts over an isolated fixture. The first makes 11 nested calls, including an
  intentional missing-file read; the second reads the package and runs `wc`; the
  third has no nested calls. The returned MIT licence and six ADRs match the fixture.
- Replaying the recorded session in the TUI verifies the visible ledger, failure
  reason, click-to-fold behaviour and Drill contents. The resulting capture was
  visually reviewed.

The runtime checks used revision `f808b0a`; the release changes only the version,
changelog and these notes. The live prompt and recipe are in
[`scripts/dev/screenshots/rig.mjs`](https://github.com/tmustier/pine-of-glass/blob/v0.16.0/scripts/dev/screenshots/rig.mjs),
in `codemodeShot()`. The live run does not verify provider token accuracy, physical
kitty image transport or every supported older Pi version.

## Update

```bash
pi update --extensions
```

Restart Pi to load the release. Cachemire remains experimental; Meantime remains
experimental and opt-in.
