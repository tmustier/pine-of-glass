# Pine of Glass 0.18.0

Traceline adds optional model summaries, compact extension notices and custom outcome
rules. Contextimate now accounts for conversation text added only to outgoing requests.
The release covers all changes since 0.17.0.

## Optional summaries and separate costs

A command that had to be cut or wrapped can show a model's gist on a `≈` line beneath
it. A cut thinking preview can show a gist too. Gists wrap without being cut, and
the command and its outcome remain visible. A gist is the model's reading, not proof.

Summaries are experimental and off by default. To enable them, add the following to
your own `~/.pi/agent/pi-traceline.json`:

```json
{
  "summaries": true
}
```

The default summary model is `openai-codex/gpt-6-luna`. To choose another, use
`"summaries": { "model": "provider/id" }`. A project config cannot enable summaries.
Requests batch as rows settle, and saved gists restore without another request.

Traceline records the full reported usage of each summary request, including partial
or unusable replies. The footer shows its estimated cost separately as
`summaries $0.001 extra`; Pi's own total stays unchanged. Tiny charges read
`<$0.001`, and missing usage stays explicitly unknown. Costs restore even when new
summaries are disabled or the model is unavailable. Older per-gist cost shares retain
an unknown remainder because failed replies were not recorded.

[#172](https://github.com/tmustier/pine-of-glass/pull/172) and
[#178](https://github.com/tmustier/pine-of-glass/pull/178).

## Compact notices and clearer commands

With reasoning hidden, extension messages and entries appear as compact trace rows
alongside tool calls. Subagent questions, results and warnings use the extension's
summary or collapsed rendering. Click or Ctrl+O opens the original block; Ctrl+T
returns control to Pi's native display.

Crowded outcome headlines keep the important result and drop cleanup facts first.
Local branch deletion reads `deleted branch docs`, and a dim `+1` marks an omitted
fact. The command behind the outcome stays readable, with other commands giving
way first. Command highlighting now reads through assignments such as
`PR_URL=$(gh pr create …)`, and wrapping keeps assignments with their command.

PRs [#173](https://github.com/tmustier/pine-of-glass/pull/173),
[#174](https://github.com/tmustier/pine-of-glass/pull/174) and
[#175](https://github.com/tmustier/pine-of-glass/pull/175).

## Custom outcome rules

Traceline's record vocabulary is plain data with runnable examples. Add rules through
`vocabulary` in your user or trusted project config, replace a built-in rule by its
id, or turn rules off with `disableVocabulary`. Other extensions can supply rules
through the `traceline:vocabulary` event.

Each rule must pass its examples before it loads. Invalid rules produce a notification
without preventing other rules from loading. Custom rules read command output;
silent-success inference remains built in.

The development script `scripts/dev/bash-corpus/draft-vocabulary.ts` can draft rules
from your own session results with a model. It checks examples against real results
and reports where the draft matches across the collected output.

PRs [#166](https://github.com/tmustier/pine-of-glass/pull/166),
[#167](https://github.com/tmustier/pine-of-glass/pull/167) and
[#168](https://github.com/tmustier/pine-of-glass/pull/168).

## Contextimate request-only accounting

Contextimate shows conversation text added by extensions only for an outgoing request
in a separate `Request-only` row. The row estimates those additions without adding
them again to the provider's total or absorbing them into harness and tool-growth
measurements. Session entries save counts, not the injected text, and attribution
survives reload and branch changes.

Native OpenAI Responses, Codex and Anthropic text requests are reconciled after
context hooks. Other formats and image-bearing requests retain the earlier
context-hook observation. The row is an estimate, not an exact token measurement;
later raw-payload rewrites and arbitrary conversation replacement are not covered.

PRs [#177](https://github.com/tmustier/pine-of-glass/pull/177) and
[#179](https://github.com/tmustier/pine-of-glass/pull/179).

## Maintenance and compatibility

Internal code is simpler across the four extensions, with narrower boundary types,
fewer single-use helpers and tests through Pi's SDK and domain interfaces. Typecheck
now covers the bash-corpus scripts.

Development and tests remain on Pi 1.3.0. The minimum supported Pi remains 0.86.0.
Cachemire and Meantime keep their existing behaviour and opt-in settings.

PRs [#170](https://github.com/tmustier/pine-of-glass/pull/170) and
[#176](https://github.com/tmustier/pine-of-glass/pull/176).

## Validation

Lint, typecheck and all 533 tests pass on Pi 1.3.0. The full terminal smoke suite
passes, including tool and reasoning clicks, Drill, pager fidelity, nested sessions,
notices, startup and reload. Smoke tests use an isolated tmux server kept alive across
the scripts.

Before release preparation, live `openai-codex/gpt-6.1-sol` runs at revision
`931f938afefdf019b6d9b9caaf9d983cdced493f` verified usable and malformed summary replies.
The main agent used medium thinking, and summaries used low thinking. Independent
checks verified the actual bash call and output, full summary usage, Pi's unchanged
native total, separate costs at 40 and 100 columns, Ctrl+T, reload and disabled
credential-free replay. The malformed-reply relay changed the prompt sent to the same
approved model, not its output or usage.

Contextimate's live attribution checks and their limits are recorded in
[the request-only verification note](../contextimate-request-messages-verification.md).
No provider billing comparison or new pricing-accuracy claim is made.

## Update

For the Git installation:

```bash
pi update --extensions
```

For an npm installation, update with `pi update`. Restart Pi or run `/reload` to load
the updated extensions.
